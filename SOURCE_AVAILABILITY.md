# Source availability

The source code corresponding to CRysTal Fantasy modifications is provided in
this repository and with the associated binary release.

Modified source files covered by the Mozilla Public License 2.0 are provided
in source form under MPL-2.0 with their original headers and notices preserved.

The upstream ConsoleMode MPL-covered source is maintained by Retro Remake in
the official ConsoleMode source repository.

Source and build information for CRysTal helper executables is provided with
the CRysTal Fantasy source distribution.
