# Modifications

CRysTal Fantasy modifies ConsoleMode 1.1.2 to add and integrate features
including:

- RPG-style profiles, progress, statistics, quests, titles, and status screens
- Random Encounter game selection with category preferences
- Expanded game-list navigation and media viewing
- SD, USB, and temporary cache modes with bounded cache maintenance
- CRysTal Archive profile and configuration backup and restore
- Additional interface, artwork, audio, preference, and accessibility options
- Installer, safe uninstaller, verification, and recovery tooling

The original ConsoleMode About/Credits screen and upstream copyright strings
are preserved.
