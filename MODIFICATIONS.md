# Modifications to Console Mode 1.1.2

CRysTal Fantasy is an unofficial modified distribution of Console Mode 1.1.2.

Project concept, design direction and testing: Hinph 
Development assistance: OpenAI tools and models

Major changes include the CRysTal profile/RPG layer, Random Encounter, Crystal
Archive backup and restore, artwork and media handling, three-state cache
storage, preference screens, statistics, quests, status effects, manual viewing
and related frontend integration.

This file is a high-level change notice. Modified source files must also carry
prominent file-level notices where required by Apache-2.0, and MPL-covered files
must retain their original MPL and copyright headers.
