# CRysTal Fantasy

**A fully featured classic RPG themed mod to Console Mode on the MiSTer FPGA**

The aim of this project was simply bring the CRT-ready MiSTer frontend experience that I wanted to use for myself to life! This functions as a mod to RetroRemake's excellent ConsoleMode frontend.

## Features:

- Interface designed to squeeze as much information and functionality onto a low resolution CRT space as possible
- Supports images, videos, and game manuals
- Built in playlog to track your play habits and time spent in games and systems. Huge for us stat nerds.
- Quickly backup profiles and game saves/states to a USB drive
- Fun RPG theme

## Install:

This version is currently compatible with 1.1.2 of ConsoleMode (https://github.com/Retro-Remake/ConsoleMode_Distribution/releases/tag/1.1.2). Make sure you have that version installed, download the sh file to your scripts folder, and run it. Don't update ConsoleMode until I release a future version of the mod or it will likely break it. I imagine the upgrade process in the future should be pretty painless... run uninstall CRysTal to revert to standard ConsoleMode, update, run new sh mod.

## CRysTal Scraper Companion app

Included is a program that will let you easily scrape your media onto your sd card. Windows only for now. Sorry. I knew the questions "how do I get all of that cool game information to work?" and "how do I convert my videos to the proper format?" were going to be a problem. I tried to make the process as easy as possible to scrape, convert, and compress all files using a simple bridge app to ES-DE. After years of playing around in game frontends, I know ES-DE is the most painless process! Also requires a free Screenscraper account.

### RPG Mode

We all have a massive collection of roms we don't touch. I thought it would be fun to include a little meta mode to encourage us all to explore some of these with an incentive to gain more XP and level up if we did. Try the random battle button! Enjoy the weird status effects.
